# English Offline v2.1

אפליקציית אנדרואיד (Expo / React Native) ללימוד אנגלית, 100% בלי אינטרנט.

## מה יש בה
- **839 מילים וביטויים** בעברית, ב-19 נושאים (`src/data/vocabulary.json`).
- **כרטיסיות** עם אנימציית היפוך, "ידעתי / עוד לא", הקראה, ערבוב, "רק חדשות", מועדפים ואפשרות "עברית קודם".
- **חזרה חכמה:** מילים חוזרות במרווחים (יום, 3, שבוע, שבועיים, חודש) לפי התשובות שלך.
- **חידון** ב-5 מצבים: אנגלית←עברית, עברית←אנגלית, האזנה, הקלדה וכתיב. 5/10/20 שאלות, טעויות מוצגות בסוף.
- **משחוק:** נקודות, רמות, רצף ימים, יעד יומי וגרף פעילות שבועי. **המילה של היום** בדף הבית.
- **חיפוש** באנגלית או בעברית, עם סינון ידועות/חדשות/מועדפים.
- **עוד:** סטטיסטיקה, מצב כהה/בהיר/אוטומטי, מהירות הקראה, רטט, גיבוי ושחזור התקדמות, איפוס.

## גרסאות אנדרואיד
- דורש **אנדרואיד 7.0 ומעלה** (Expo SDK 52). הקראה בלי אינטרנט דורשת קול אנגלי מותקן (הגדרות ← מערכת ← שפה ← פלט טקסט לדיבור).

## הרצה
```bash
npm install
npx expo install --fix
npx expo start
```

## בניית APK ב-GitHub
הקובץ `.github/workflows/main.yml` כבר מוכן. אחרי העלאה: **Actions ← Build APK ← Run workflow**. כשהבנייה מסתיימת, מורידים את `english-offline-apk` מ-Artifacts.

## הוספת מילים
ערוך את `src/data/vocabulary.json`: כל נושא הוא `{ id, name, emoji, color, words: [{ en, he }] }`.
**הוסף מילים חדשות רק בסוף רשימת הנושא**: ההתקדמות נשמרת לפי מיקום המילה, ושינוי סדר או מחיקה באמצע ישבשו אותה.
