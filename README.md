# English Offline

אפליקציית אנדרואיד (Expo / React Native) ללימוד אוצר מילים באנגלית. כל המילים והתרגומים נמצאים בתוך האפליקציה, ולכן היא עובדת בלי אינטרנט.

## מה יש בה
- **כרטיסיות** עם אנימציית היפוך, הקראה, סימון "ידועה" וערבוב, לפי נושא.
- **חידון** של 10 שאלות בשני כיוונים (אנגלית ← עברית ועברית ← אנגלית), עם ניקוד ושיא אישי.
- **חיפוש** באנגלית או בעברית.
- הקראה דרך מנוע ההקראה של המכשיר (`expo-speech`). כדי שתעבוד בלי אינטרנט צריך קול אנגלי מותקן בהגדרות הטלפון (פלט טקסט לדיבור).

## הרצה
```bash
npm install
npx expo install --fix   # מיישר גרסאות חבילות ל-SDK שלך
npx expo start
```
סרוק את הקוד עם Expo Go, או הקש `a` לאמולטור אנדרואיד.

## בניית APK
```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview
```

## הוספת מילים
ערוך את `src/data/vocabulary.json`. כל נושא הוא `{ id, name, emoji, words: [{ en, he }] }`.
