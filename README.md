# English Offline v2

אפליקציית אנדרואיד (Expo / React Native) ללימוד אנגלית, 100% בלי אינטרנט.

## מה יש בה
- **807 מילים וביטויים** בעברית, ב-19 נושאים (`src/data/vocabulary.json`).
- **כרטיסיות** עם אנימציית היפוך, כפתורי "ידעתי / עוד לא", הקראה, ערבוב ותצוגת "רק חדשות".
- **חידון** בשלושה מצבים: אנגלית ← עברית, עברית ← אנגלית, והאזנה. כולל רצף תשובות, כוכבים, וחזרה על טעויות.
- **משחוק:** נקודות, רמות, רצף ימים ויעד יומי.
- **חיפוש** באנגלית או בעברית, עם סינון ידועות/חדשות.
- **מצב כהה**, רטט עדין, והכול נשמר במכשיר.

## גרסאות אנדרואיד
- האפליקציה (ה-APK) דורשת **אנדרואיד 7.0 ומעלה** (API 24), בהגדרות הרגילות של Expo SDK 52.
- פועלת גם על גרסאות חדשות יותר (אנדרואיד 14 ומעלה).
- **Expo Go** לצורך פיתוח דורש גרסה עדכנית של האפליקציה מחנות Google Play.
- הקראה בלי אינטרנט דורשת קול אנגלי מותקן (הגדרות ← מערכת ← שפה ← פלט טקסט לדיבור, למשל Google).

## הרצה
```bash
npm install
npx expo install --fix
npx expo start
```

## בניית APK ב-GitHub
הקובץ `.github/workflows/build.yml` כבר מוכן. אחרי העלאה: **Actions ← Build APK ← Run workflow**. כשהבנייה מסתיימת, מורידים את `english-offline-apk` מ-Artifacts.
(בנייה מקומית: `eas build -p android --profile preview`).

## הוספת מילים
ערוך את `src/data/vocabulary.json`: כל נושא הוא `{ id, name, emoji, color, words: [{ en, he }] }`.
